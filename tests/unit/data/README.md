# Unit-test data

Tiny R data files for `tests/unit/test_config.py`, `test_rdata_io.py` and `test_runstats.py`, generated by
`Rscript tests/unit/data/make_data.R` (R 4.6.1, packages gms, yaml, jsonlite; magclass optional), together with
`expected.json`, `yaml_scalars.json` and `dst.rda` which record what R computed for them, so the tests never need R.
The two YAML inputs (`config.yml.txt` from `gms::saveConfig`, `yaml_scalars.yml.txt`) carry a `.txt` suffix because
the repository's `check-yaml` pre-commit hook cannot construct the gms tags (`!<namedVector>`, `!<character>`); the
tests copy `config.yml.txt` to a temporary `config.yml` before loading it.
